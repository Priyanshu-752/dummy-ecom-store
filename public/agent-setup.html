Commerce agent integration check

This developer page uses the same shopper cookie as the storefront on this origin. Open it in the same browser as your shopping bag.

1. Check the connection

2. Verify the website cart
In the merchant console, open Test → Open live preview → View my cart. Paste its challenge below. Generate a proof here, then paste the result into the merchant console’s Signed cart proof field and choose Connect preview cart.
This proof expires after five minutes and is bound to the challenge. The signing secret stays on the server.
3. Check both directions
  1. Add a mug on the storefront, then ask the assistant to show your cart.
  2. Ask the assistant to add a notebook, then open the store’s normal bag.
  3. Change a quantity on the website and confirm the assistant sees the same quantity.
For local-service testing, keep http://127.0.0.1:5199 running on this computer.
